# Лабораторная №2. Методы решения нелинейных уравнений — подробный разбор

Уравнение варианта 26: f(x) = x³ − 0,1x² + 0,4x + 2 = 0.

**Как пользоваться.** Читай по порядку: каждый следующий раздел опирается на предыдущий. Сначала разделы 1–3 (откуда берётся отрезок \[−2; −1\] и почему график выглядит именно так) — это фундамент для всех пяти методов. Потом по одному разделу на метод (4–8). В конце — сравнение, что писать в рукописный отчёт, как рисовать рисунки и вопросы к защите с ответами. Все числа в документе пересчитаны заново и совпадают с выводом программы main.cpp.

## 1. Что требуется в работе

Нужно найти число x, при котором f(x) = 0. Формулы для кубических уравнений существуют, но громоздкие, поэтому в вычислительной математике корень ищут **численно**: строят последовательность чисел x₁, x₂, x₃, …, которая всё ближе к настоящему корню ξ (буква «кси»), и останавливаются, когда достигнута нужная точность ε = 10⁻⁶ = 0,000001.

Работа состоит из двух этапов:

1. **Отделение корня** — найти отрезок \[a; b\], на котором лежит ровно один корень. Без этого численные методы не знают, где искать.
2. **Уточнение корня** — пятью методами (половинного деления, хорд, Ньютона, комбинированный, простых итераций) довести приближение до точности ε и сравнить методы по числу шагов.

Ответ для самопроверки: ξ ≈ −1,1249117, с шестью знаками −1,124912. Все пять методов должны к нему прийти.

## 2. Отделение корня шаг за шагом

### 2.1. Что значит «корень отделён»

Корень отделён на \[a; b\], если выполнены три условия:

- f(x) непрерывна на \[a; b\] (у многочлена так всегда);
- f(a)·f(b) < 0, то есть на концах значения разных знаков. Тогда по теореме о промежуточных значениях график обязан пересечь ось Ox — корень **существует**;
- f(x) монотонна на \[a; b\] (всё время растёт или всё время убывает). Тогда график пересекает ось только один раз — корень **единственный**.

Первое условие даёт «хотя бы один корень», третье — «не больше одного». Вместе — ровно один.

### 2.2. Шаг 1. Производная и монотонность

Находим производную: f′(x) = 3x² − 0,2x + 0,4.

Нам нужен знак f′. Это парабола ветвями вверх (коэффициент 3 > 0). Считаем дискриминант:

D = (−0,2)² − 4·3·0,4 = 0,04 − 4,8 = −4,76 < 0.

Отрицательный дискриминант значит, что парабола **не пересекает** ось Ox, а раз ветви вверх, она целиком лежит выше оси. Значит f′(x) > 0 при любом x. Функция f(x) **строго возрастает на всей числовой прямой**, поэтому её график пересекает ось Ox не более одного раза, а значит корень не больше одного.

Зачем вообще искали производную: в общем случае корни f′ — это точки экстремума, между которыми график может «горбом» пересекать ось несколько раз; именно в этих точках составляют таблицу знаков. Здесь экстремумов нет, поэтому задача упрощается.

### 2.3. Шаг 2. Знаки на бесконечностях

При x → −∞ в многочлене главным становится x³, он отрицателен, значит f < 0. При x → +∞ главным остаётся x³, но он положителен, значит f > 0. Знак меняется с «−» на «+», то есть корень точно есть, и (из шага 1) он один. Но «где-то на прямой» нам не подходит — нужен конкретный короткий отрезок.

### 2.4. Шаг 3. Почему именно \[−2; −1\]

Методичка требует сузить промежуток до длины не больше 1. Для этого берут подряд целые точки и считаем в них значения функции, пока знак не сменится:

- f(−3) = −27 − 0,9 − 1,2 + 2 = −27,1
- f(−2) = −8 − 0,4 − 0,8 + 2 = −7,2
- f(−1) = −1 − 0,1 − 0,4 + 2 = 0,5
- f(0) = 0 − 0 + 0 + 2 = 2
- f(1) = 1 − 0,1 + 0,4 + 2 = 3,3

| x | −3 | −2 | −1 | 0 | 1 |
| --- | --- | --- | --- | --- | --- |
| f(x) | −27,1 | −7,2 | 0,5 | 2 | 3,3 |
| знак | − | − | + | + | + |

Знак меняется **ровно один раз — между x = −2 и x = −1**. На парах (−3; −2) оба значения отрицательны, на (−1; 0) и (0; 1) оба положительны — там корня нет. Поэтому \[−2; −1\] — единственный подходящий отрезок с целыми концами, длина его равна 1.

Проверка условий отделения: f(−2)·f(−1) = −7,2 · 0,5 = −3,6 < 0 — условие смены знака выполнено; функция монотонна (шаг 1) — условие единственности выполнено.

**Можно ли выбрать другой отрезок?** Да, математически подойдёт любой отрезок, внутри которого знак меняется: например, \[−1,5; −1\] (f(−1,5) = −2,2) или совсем узкий \[−1,2; −1,1\] (f(−1,2) = −0,352, f(−1,1) = 0,108). Но стандартный выбор по методичке — целые концы и длина 1: так проще считать вручную и не нужно «угадывать». На преподавателя это отвечает так: «Я брал целые точки подряд, пока знак не поменялся; смена произошла между −2 и −1».

Замечание, которое полезно знать: чем уже начальный отрезок, тем меньше шагов у метода половинного деления. У остальных методов важна не длина, а то, что корень внутри и выполнены условия на производные.

### 2.5. Шаг 4. Вторая производная и границы для f′

Вторая производная: f″(x) = 6x − 0,2.

На отрезке \[−2; −1\] имеем 6x ∈ \[−12; −6\], поэтому f″ ∈ \[−12,2; −6,2\] — она **отрицательна на всём отрезке и не меняет знак**. Это важное условие для методов хорд, Ньютона и комбинированного: пока f″ сохраняет знак, график не меняет характер изгиба и методы ведут себя предсказуемо.

Из f″ < 0 следует, что f′ **убывает** на отрезке, значит наибольшее значение f′ — в левом конце, наименьшее — в правом:

- f′(−2) = 3·4 + 0,4 + 0,4 = 12,8;
- f′(−1) = 3 + 0,2 + 0,4 = 3,6.

Итак, 3,6 ≤ f′(x) ≤ 12,8. Обозначим m = 3,6 (минимум) и Q = 12,8 (максимум). Они понадобятся: Q — для метода итераций (выбор k), m — для оценки погрешности.

**Оценка погрешности через m.** По теореме Лагранжа f(x) − f(ξ) = f′(c)·(x − ξ) для некоторой точки c между x и ξ. Так как f(ξ) = 0, получаем |x − ξ| = |f(x)| / |f′(c)| ≤ |f(x)| / m. То есть, зная невязку |f(x)| (насколько f(x) далека от нуля), можно гарантированно оценить расстояние до корня: |x − ξ| ≤ |f(x)| / 3,6.

### 2.6. Итог отделения (что записать в отчёт)

- f′(x) = 3x² − 0,2x + 0,4, D = −4,76 < 0 ⇒ f′ > 0 ⇒ f строго возрастает ⇒ корень не более одного;
- f(−∞) < 0, f(+∞) > 0 ⇒ корень ровно один;
- таблица знаков в точках −3, −2, −1, 0, 1 ⇒ корень на \[−2; −1\];
- f(−2) = −7,2 < 0, f(−1) = 0,5 > 0;
- f″(x) = 6x − 0,2 < 0 на \[−2; −1\]; 3,6 ≤ f′ ≤ 12,8.

## 3. Как выглядит график на \[−2; −1\] — ключ ко всем методам

На отрезке f′ > 0 (функция растёт) и f″ < 0 (график изогнут «горкой», выпуклый вверх). Наглядно: слева график крутой (наклон 12,8), справа — пологий (наклон 3,6). Левый конец (−2; −7,2) глубоко под осью, правый конец (−1; 0,5) чуть выше оси, а само пересечение с осью в точке −1,1249 лежит очень близко к правому концу.

Для графиков такого вида верны два геометрических факта:

1. **Хорда** (отрезок между двумя точками графика) лежит **ниже** графика.
2. **Касательная** в любой точке лежит **выше** графика.

Отсюда вытекает то, что потом объясняет поведение методов:

- Точка x₁, где хорда пересекает ось Ox, лежит **правее корня**: в ней хорда равна 0, а график над хордой, значит f(x₁) ≥ 0, а растущая функция неотрицательна только правее корня.
- Точка, где касательная пересекает ось Ox, лежит **левее корня**: в ней касательная равна 0, а график под касательной, значит f ≤ 0 — то есть мы левее корня.

Поэтому хорды дают приближения **справа** от корня («по избытку»), а касательные — **слева** («по недостатку»). Комбинированный метод использует оба факта сразу и «зажимает» корень между ними.

## 4. Общие понятия: что такое «шаг», «ошибка» и «точность»

Эти слова встречаются в каждом методе, поэтому договоримся о них один раз.

- **ξ** — истинный корень (нам он заранее неизвестен; для проверки используем значение ξ ≈ −1,12491165, посчитанное независимым решателем).
- **xₙ** — приближение после n-го шага.
- **Ошибка** = |xₙ − ξ| — насколько мы реально далеки от корня. В программе её посчитать нельзя (ξ не знаем), но для отчёта можно оценить.
- **Невязка** = |f(xₙ)| — насколько приближение «не дотягивает» до уравнения. Невязка мала, когда мала ошибка, но это разные числа: |xₙ − ξ| ≤ |f(xₙ)|/3,6.
- **ε = 10⁻⁶** — требуемая точность. В программе: `const double EPS = 1e-6;`.
- **Шаг (итерация)** — один проход цикла `while` в функции метода. Счётчик `n++` считает именно эти проходы. Это значит, что «шаги» разных методов не вполне сопоставимы по трудоёмкости (на шаге Ньютона считаются f и f′, на шаге хорд только f), но по ним удобно сравнивать скорость.
- **Критерий остановки.** Мы не знаем ошибку, поэтому останавливаемся, когда соседние приближения почти не отличаются: |xₙ₊₁ − xₙ| < ε. Для половинного деления — когда длина отрезка не больше ε. Практически ошибка получается меньше ε (проверено ниже в таблицах), но формально разность соседних значений не всегда доказывает это.
- **Линейная сходимость** — на каждом шаге ошибка умножается примерно на одно и то же число q < 1 (например, на 0,46). Чтобы получить каждые следующие 3 верных знака, нужно примерно одно и то же число шагов.
- **Квадратичная сходимость** — ошибка следующего шага примерно равна квадрату предыдущей: было 10⁻³ — стало 10⁻⁶, потом 10⁻¹², т.е. число верных знаков примерно удваивается.
- **Подход с одной стороны / с двух сторон** — лежат ли все приближения по одну сторону от корня (монотонно приближаются) или корень зажат между двумя последовательностями.

**Как читать код.** Каждый метод — отдельная функция вида `void метод(double a, double b, double& x, int& n)`. Символ `&` означает ссылку: функция не возвращает значения, а записывает ответ прямо в переменные `root` и `steps` из `main`. Затем `main` печатает строку таблицы и использует те же переменные для следующего метода. Функции `f`, `df`, `ddf` вычисляют f(x), f′(x), f″(x).

## 5. Метод половинного деления (дихотомии)

### 5.1. Идея

Корень лежит на \[a; b\], значения на концах разных знаков. Возьмём середину c = (a + b)/2 и посмотрим на знак f(c). Корень находится в той половине, на концах которой знаки по-прежнему разные. Оставляем эту половину и повторяем. Отрезок каждый раз сжимается вдвое, а корень всё время остаётся внутри.

### 5.2. Условия сходимости и выбор начальных данных

Нужно только: f непрерывна и f(a)·f(b) < 0. У нас f(−2)·f(−1) = −3,6 < 0. Начальное приближение выбирать не надо — берём весь отрезок \[−2; −1\]. Производные методу не нужны. Метод сходится **всегда**, если условие выполнено.

### 5.3. Первые шаги вручную

Начало: a = −2, b = −1. На шаге n: c = (a + b)/2.

| n | c | f(c) | знак f(c) | что делаем | новый отрезок |
| --- | --- | --- | --- | --- | --- |
| 1 | −1,5 | −2,2 | − | знак как у f(a), значит корень правее: a := c | \[−1,5; −1\] |
| 2 | −1,25 | −0,6094 | − | a := c | \[−1,25; −1\] |
| 3 | −1,125 | −0,00039 | − | a := c | \[−1,125; −1\] |
| 4 | −1,0625 | 0,2626 | + | знак как у f(b), значит корень левее: b := c | \[−1,125; −1,0625\] |
| 5 | −1,09375 | 0,1344 | + | b := c | \[−1,125; −1,09375\] |
| 6 | −1,109375 | 0,0679 | + | b := c | \[−1,125; −1,109375\] |

Полная таблица всех 20 шагов приведена в приложении А отчёта. Обрати внимание: уже после шага 3 левый конец −1,125 отличается от корня меньше чем на 10⁻⁴, но метод этого «не знает» и продолжает делить пополам; в этом его и скорость (предсказуема), и недостаток (не использует информацию о форме функции).

### 5.4. Почему ровно 20 шагов

Длина отрезка после n шагов равна (b − a)/2ⁿ = 1/2ⁿ. Нужно 1/2ⁿ ≤ 10⁻⁶, то есть 2ⁿ ≥ 10⁶, n ≥ log₂(10⁶) ≈ 19,93. Значит n = 20. Проверка: 1/2¹⁹ ≈ 1,9·10⁻⁶ (ещё больше ε), 1/2²⁰ ≈ 9,54·10⁻⁷ (уже меньше ε). Формула из методички n ≈ \[ln((b−a)/ε)/ln 2\] + 1 = \[19,93\] + 1 = 20 даёт то же самое.

### 5.5. Код построчно

```
while (fabs(b - a) > EPS) {   // пока отрезок длиннее ε
    x = (a + b) / 2.0;        // середина
    if (f(a) * f(x) <= 0) b = x;   // знаки f(a) и f(x) разные: корень слева, правый конец переносим в середину
    else a = x;                    // знаки одинаковые: корень справа, левый конец переносим в середину
    n++;                           // посчитали шаг
}
x = (a + b) / 2.0;            // ответ — середина последнего отрезка
```

Почему в условии «≤ 0», а не «< 0»: если f(x) случайно оказалась ровно нулём (корень найден точно), произведение равно 0 и корень остаётся в сохранённой половине, ничего не ломается.

### 5.6. Результат, ошибка и характер приближения

Ответ программы −1,1249118, 20 шагов. Корень заключён в отрезке длиной меньше 10⁻⁶, а мы берём его середину, поэтому гарантированная ошибка не больше половины длины, около 5·10⁻⁷. Реальная ошибка 1,3·10⁻⁷.

Характер приближения: **с двух сторон**. Левые концы aₙ не убывают (двигаются только вправо), правые bₙ не возрастают (только влево), корень всегда между ними. Сходимость линейная со знаменателем 1/2. Из-за этого погрешность известна в ходе вычислений: она не больше (bₙ − aₙ)/2.

**Рисунок для защиты:** ось x с точками a, b, c₁, c₂, c₃; график; под осью три отрезка \[a, b\], \[a₁, b₁\], \[a₂, b₂\], каждый вдвое короче предыдущего.

## 6. Метод хорд

### 6.1. Идея

Вместо деления пополам используем форму графика. Проводим прямую (хорду) через две точки графика и берём точку её пересечения с осью Ox как новое приближение. Если график не слишком сильно изгибается, эта точка ближе к корню, чем середина.

Хорда проходит через неподвижную точку P = (c, f(c)) и текущую точку Q = (xₙ, f(xₙ)). Из подобия треугольников (или из уравнения прямой): (xₙ − xₙ₊₁)/(xₙ − c) = f(xₙ)/(f(xₙ) − f(c)), откуда

**xₙ₊₁ = xₙ − f(xₙ)·(xₙ − c)/(f(xₙ) − f(c)).**

Если записать наклон хорды k = (f(xₙ) − f(c))/(xₙ − c), то xₙ₊₁ = xₙ − f(xₙ)/k — это та же формула, что у метода Ньютона, но с наклоном хорды вместо наклона касательной.

### 6.2. Какой конец неподвижный и почему (обоснование выбора)

Правило из методички: неподвижным берём конец, где f(x)·f″(x) > 0; начальное приближение x₀ — другой конец.

Проверим концы:

- В точке a = −2: f(−2) = −7,2 < 0 и f″(−2) = −12,2 < 0, произведение (−7,2)·(−12,2) = 87,84 > 0 — **подходит, a неподвижен**.
- В точке b = −1: f(−1) = 0,5 > 0, f″(−1) = −6,2 < 0, произведение отрицательно — b будет стартовой точкой x₀ = −1.

Смысл правила (опираемся на раздел 3): хорда всегда пересекает ось правее корня. Значит, все приближения будут справа от корня, и стартовать надо тоже справа, в точке −1, где f > 0. Неподвижная точка — на другой стороне, слева (a = −2). В итоге каждое новое приближение лежит правее корня и приближается к нему монотонно слева, не перескакивая.

### 6.3. Условия сходимости

f′ и f″ сохраняют знак на \[a; b\] (проверено в разделе 2: f′ > 0, f″ < 0). Неподвижный конец выбран по правилу. Тогда последовательность xₙ монотонна, ограничена и сходится к корню.

### 6.4. Первые шаги вручную

x₀ = −1, f(x₀) = 0,5; неподвижная точка c = −2, f(c) = −7,2.

Шаг 1: f(x₀) − f(c) = 0,5 − (−7,2) = 7,7; x₁ = −1 − 0,5·(−1 − (−2))/7,7 = −1 − 0,5/7,7 = −1 − 0,0649351 = **−1,0649351**, f(x₁) = 0,2529.

Отношение соседних ошибок почти постоянно, около 0,46 (0,0600/0,1249 ≈ 0,48; 0,0282/0,0600 ≈ 0,47; 0,0132/0,0282 ≈ 0,47). Это и есть **линейная сходимость**, число 0,46 — её знаменатель. Оттуда же число шагов: 0,1249·0,46ⁿ < 10⁻⁶ ⇒ n ≈ 15–16, в программе 16 шагов.

### 6.5. Код построчно

```
if (f(a) * ddf(a) > 0) { fixed_end = a; x_curr = b; }   // выбор неподвижного конца по правилу f·f'' > 0
else                   { fixed_end = b; x_curr = a; }
while (true) {
    double x_next = x_curr - f(x_curr) / (f(x_curr) - f(fixed_end)) * (x_curr - fixed_end);   // формула хорды
    n++;
    if (fabs(x_next - x_curr) < EPS) { x = x_next; break; }   // остановка, когда сдвиг меньше ε
    x_curr = x_next;
}
```

У нас условие истинно (87,84 > 0), поэтому fixed\_end = −2, x\_curr = −1. Это та же формула, что в разделе 6.1.

### 6.6. Результат и характер приближения

Ответ −1,1249111, 16 шагов. Реальная ошибка 5,9·10⁻⁷ — меньше ε, хотя последний сдвиг был около 7·10⁻⁷: при линейной сходимости с q = 0,46 остаток после последнего шага примерно равен сдвигу, умноженному на q/(1 − q) ≈ 0,85. Приближение **с одной стороны**: все xₙ > ξ и монотонно убывают. Оценка ошибки: |xₙ − ξ| ≤ |f(xₙ)|/3,6 = 2,6·10⁻⁶/3,6 ≈ 7,3·10⁻⁷.

**Рисунок для защиты:** кривая, возрастающая и изогнутая вверх; слева внизу точка A = (a, f(a)) (неподвижная), справа точка (b, f(b)) выше оси; хорда из A в эту точку пересекает ось в x₁ (правее корня); из x₁ поднимаемся вертикально до графика, снова проводим хорду из A, получаем x₂ ещё ближе к корню.

## 7. Метод Ньютона (метод касательных)

### 7.1. Идея и вывод формулы

В текущей точке (xₙ, f(xₙ)) проводим касательную к графику и берём точку её пересечения с осью Ox. Уравнение касательной: y = f(xₙ) + f′(xₙ)·(x − xₙ). Приравниваем y = 0 и решаем: x = xₙ − f(xₙ)/f′(xₙ). Получаем

**xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ).**

Смысл: вблизи точки функция почти совпадает со своей касательной, поэтому корень касательной — хорошее приближение корня функции.

### 7.2. Условия сходимости и выбор x₀

Условия: f′ и f″ сохраняют знак на \[a; b\] (у нас f′ > 0, f″ < 0 — выполнено), и x₀ выбирается как тот конец, где f(x₀)·f″(x₀) > 0.

- x₀ = −2: f(−2)·f″(−2) = (−7,2)·(−12,2) = 87,84 > 0 — **подходит**.
- x₀ = −1: f(−1)·f″(−1) = 0,5·(−6,2) = −3,1 < 0 — не удовлетворяет правилу.

Смысл выбора через геометрию (раздел 3): касательная к такому графику лежит выше него, поэтому пересечение с осью всегда оказывается **левее** корня. Если начать слева (в −2), то все приближения остаются слева от корня и монотонно растут к нему, и мы гарантированно не выходим за пределы отрезка.

**Нюанс для защиты.** Правило f·f″ > 0 — достаточное условие, а не необходимое: оно гарантирует монотонную сходимость. Если взять x₀ = −1, первая же касательная даст x₁ = −1 − 0,5/3,6 = −1,1389 (левее корня, внутри отрезка), и дальше метод тоже сошёлся бы (проверка: −1,1389; −1,125063; −1,1249117; −1,1249117, это 4 шага). Но в общем случае первая касательная от «неправильного» конца может выбросить за пределы отрезка, поэтому следуют правилу и берут левый конец.

### 7.3. Первые шаги вручную

Шаг 1: f(−2) = −7,2; f′(−2) = 3·4 + 0,4 + 0,4 = 12,8. x₁ = −2 − (−7,2)/12,8 = −2 + 0,5625 = **−1,4375**.

Шаг 2: f(−1,4375) = −1,7521; f′(−1,4375) = 3·2,0664 + 0,2875 + 0,4 = 6,8867. x₂ = −1,4375 + 1,7521/6,8867 = −1,4375 + 0,2544 = **−1,1831**.

Ошибки: 2,5·10⁻³ → 5,0·10⁻⁶ → 1,9·10⁻¹¹. Каждая следующая примерно равна квадрату предыдущей, умноженному на константу C = |f″|/(2|f′|) ≈ 6,9/(2·4,42) ≈ 0,78: (2,5·10⁻³)²·0,78 ≈ 4,9·10⁻⁶; (5,0·10⁻⁶)²·0,78 ≈ 1,9·10⁻¹¹. Число верных знаков удваивается: 2 → 5 → 10.

**Почему 6 шагов, хотя после 5-го ошибка уже 10⁻¹¹.** Условие остановки — разность соседних приближений. После 5-го шага |x₅ − x₄| = 4,9·10⁻⁶ > ε, останавливаться рано. На 6-м шаге |x₆ − x₅| ≈ 2·10⁻¹¹ < ε — стоп. То есть последний шаг служит подтверждением; реальная точность намного лучше требуемой.

### 7.5. Код

```
double x_curr = (f(a) * ddf(a) > 0) ? a : b;   // выбор x0 по правилу f·f'' > 0: здесь a = -2

    n++;
    if (fabs(x_next - x_curr) < EPS) { x = x_next; break; }
    x_curr = x_next;
}
```

Результат: −1,1249117, 6 шагов. Приближение **с одной стороны**: все xₙ (кроме начального) лежат слева от корня и возрастают. Погрешность оценивается как |f(xₙ)|/m, здесь практически 0.

**Рисунок для защиты:** слева внизу точка (x₀, f(x₀)); от неё касательная вверх-вправо до пересечения с осью в x₁; из x₁ вертикаль до графика, новая (более пологая) касательная, x₂ и т. д. Каждая следующая касательная пересекает ось всё ближе к корню.

## 8. Комбинированный метод хорд и касательных

### 8.1. Идея

Соединяем два метода. Из раздела 3: касательная даёт приближение **слева** от корня, хорда — **справа**. Строим сразу две последовательности: xₙ (по недостатку, слева) и x̄ₙ (по избытку, справа; «x с чертой»). Корень всё время зажат между ними: xₙ < ξ < x̄ₙ.

Формулы (случай f(a)·f″(a) > 0, как у нас):

- xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ) — шаг касательной из левой точки;
- x̄ₙ₊₁ = x̄ₙ − f(x̄ₙ)·(x̄ₙ − xₙ)/(f(x̄ₙ) − f(xₙ)) — шаг хорды, проведённой через левую и правую текущие точки;
- стартуем с x₀ = a = −2, x̄₀ = b = −1.

### 8.2. Условия и выбор начальных приближений

Те же, что у методов хорд и Ньютона: f′ и f″ сохраняют знак; f(a)·f″(a) = 87,84 > 0, поэтому касательная строится от a (левого конца), хорда — от b.

### 8.3. Таблица шагов

| --- | --- | --- | --- |

| 1 | −1,4375000 | −1,0649351 | 0,3725649 |

Ручной расчёт шага 1: x₁ — это тот же Ньютон: −1,4375. x̄₁ — это та же первая хорда: −1 − 0,5·1/7,7 = −1,0649351. Шаг 2: x₂ = −1,1830828 (Ньютон из x₁); x̄₂ = −1,0649351 − 0,2529·(−1,0649351 + 1,4375)/(0,2529 + 1,7521) = −1,0649351 − 0,0470 = −1,1119.

### 8.4. Остановка, ответ и почему 5 шагов

Критерий: |x̄ₙ − xₙ| < ε. После 4-го шага разность 6,1·10⁻⁶ > ε, после 5-го — 2,4·10⁻¹¹ < ε, поэтому n = 5. Ответ — среднее арифметическое (−1,1249117), а так как корень лежит между xₙ и x̄ₙ, ошибка не больше разности, то есть ≤ 2,4·10⁻¹¹. Фактическая ошибка 7,4·10⁻¹².

Обрати внимание: левая последовательность xₙ полностью совпадает с последовательностью метода Ньютона. Комбинированный метод закончился на шаг раньше только потому, что он **видит** оба конца: убедиться в точности можно сразу, по сжавшейся вилке, а у Ньютона нужен ещё один «проверочный» шаг.

### 8.5. Код

```
if (f(a) * ddf(a) > 0) { x_n = a; x_bar = b; }     // левая точка (касательная) и правая (хорда)
else                   { x_n = b; x_bar = a; }
while (true) {
    double x_n_next   = x_n - f(x_n) / df(x_n);   // касательная
    double x_bar_next = x_bar - f(x_bar) / (f(x_bar) - f(x_n)) * (x_bar - x_n);   // хорда
    n++;
    if (fabs(x_n_next - x_bar_next) < EPS) { x = (x_n_next + x_bar_next) / 2.0; break; }
    x_n = x_n_next;  x_bar = x_bar_next;
}
```

Характер приближения: **с двух сторон**, сходимость квадратичная (левая сторона — Ньютон; вилка схлопывается так же быстро).

**Рисунок для защиты:** график, слева точка A = (x₀, f(x₀)) с касательной к оси (пересечение x₁), справа точка B = (x̄₀, f(x̄₀)); хорда AB пересекает ось в x̄₁. На оси два отрезка: от x₀ до x̄₀, затем от x₁ до x̄₁ — вилка сужается.

## 9. Метод простых итераций

### 9.1. Идея

Переписываем f(x) = 0 в виде x = φ(x) и считаем xₙ₊₁ = φ(xₙ), начиная с любой точки x₀. Если последовательность сходится, а φ непрерывна, то предел — корень (он удовлетворяет x = φ(x), то есть исходному уравнению). Геометрически корень — точка пересечения графиков y = x и y = φ(x).

### 9.2. Как получен φ

В программе используется стандартное приведение **φ(x) = x − f(x)/k**, где k — постоянное число. Если x = φ(x), то x = x − f(x)/k, откуда f(x) = 0 (при k ≠ 0) — корень нужного уравнения сохранён. Задача — подобрать k так, чтобы итерации сходились.

### 9.3. Выбор k (обоснование)

Достаточное условие сходимости: |φ′(x)| ≤ q < 1 на отрезке. Находим φ′(x) = 1 − f′(x)/k. Мы знаем 3,6 ≤ f′(x) ≤ 12,8 (раздел 2.5). Берём k > 0 (знак k должен совпадать со знаком f′). Тогда 1 − f′/k < 1 всегда; нужно ещё, чтобы 1 − f′/k > −1, то есть f′/k < 2, то есть k > f′/2. Для всех x сразу это даёт **k > Q/2 = 12,8/2 = 6,4**. Поэтому в программе k = Q/2 + 1 = 7,4 (с небольшим запасом).

Проверка: φ′(x) принимает значения от 1 − 12,8/7,4 = −0,73 до 1 − 3,6/7,4 = +0,51. Значит |φ′| ≤ q = 0,73 < 1 — условие выполнено. Также φ переводит отрезок в себя: значения φ на \[−2; −1\] лежат примерно между −1,20 и −1,03, это внутри \[−2; −1\].

**Как Q находится в программе.** Цикл перебирает точки t = a, a + 0,01, … и берёт максимум |f′(t)|. Здесь максимум достигается в самом левом конце t = −2 (f′ убывает), поэтому цикл находит точно 12,8. В общем случае сетка не доказывает максимум строго, но для нашей функции результат совпадает с аналитическим.

### 9.4. Начальное приближение и первые шаги

При |φ′| ≤ q < 1 метод сходится из любой точки отрезка, поэтому берём x₀ = a = −2.

Шаг 1: x₁ = −2 − (−7,2)/7,4 = −2 + 0,97297 = **−1,02703**. Далее:

### 9.5. Характер приближения: сначала «зигзаг», потом «лестница»

В точке x₀ = −2 производная φ′(−2) = −0,73 < 0, поэтому первый шаг перебрасывает нас **на другую сторону корня** (с −2 на −1,027 — справа). Дальше в окрестности корня φ′ > 0 (φ′(ξ) ≈ 0,40), и последовательность монотонно убывает к корню справа — «лестница». Правило: φ′ > 0 — монотонно с одной стороны; φ′ < 0 — по спирали, перескакивая через корень.

Оценка погрешности: |ξ − xₙ| ≤ q/(1 − q)·|xₙ − xₙ₋₁|. Для области справа от корня q ≈ 0,49 (значение φ′(x₁)), множитель 0,96.

### 9.6. Код

```
double Q = 0;
for (double t = a; t <= b; t += 0.01)
    if (fabs(df(t)) > Q) Q = fabs(df(t));   // Q = max|f'| на отрезке (= 12,8)
double k = Q / 2.0 + 1.0;                  // k = 7,4 > Q/2
double x_curr = a;                         // x0 = -2
while (true) {
    double x_next = x_curr - f(x_curr) / k;   // x_{n+1} = φ(x_n)
    n++;
    if (fabs(x_next - x_curr) < EPS) { x = x_next; break; }
    x_curr = x_next;
}
```

Результат: −1,1249113, 15 шагов, реальная ошибка 3,5·10⁻⁷.

**Рисунок для защиты:** оси; прямая y = x; пологая кривая y = φ(x), пересекающая её в точке ξ; от x₀ вертикаль до кривой, горизонталь до прямой, снова вертикаль до кривой и т. д. — «лесенка» (если кривая возрастает) или «спираль» (если убывает).

## 12. Вопросы на защите и ответы

**Почему у уравнения один корень?** f′(x) = 3x² − 0,2x + 0,4 имеет D = −4,76 < 0 и положительный старший коэффициент, значит f′ > 0 везде, f строго возрастает и пересекает ось не более одного раза; на концах \[−2; −1\] значения −7,2 и 0,5 разных знаков, значит корень есть.

**Почему взяли отрезок \[−2; −1\]?** Вычислили f в целых точках −3, −2, −1, 0, 1: −27,1; −7,2; 0,5; 2; 3,3. Знак меняется только между −2 и −1. Длина отрезка 1, как требует методичка.

**Зачем нужна вторая производная?** Она показывает изгиб графика. Если f″ не меняет знак, хорда лежит по одну сторону от графика, а касательная — по другую, поэтому методы ведут себя предсказуемо. Через f·f″ выбирают неподвижный конец хорд и старт Ньютона.

**Почему в хордах неподвижен конец −2?** f(−2)·f″(−2) > 0. Геометрически: хорды дают приближения справа от корня, стартуем справа (x₀ = −1), неподвижная точка слева — движение монотонное, без перескоков.

**Почему Ньютон стартует с −2, а не с −1?** По достаточному условию f(x₀)·f″(x₀) > 0 (в −2 оно выполнено, в −1 нет). Касательная лежит над графиком, поэтому все приближения слева от корня и монотонно растут. (Старт из −1 здесь тоже сошёлся бы: условие достаточное, не необходимое.)

**Почему дихотомия делает 20 шагов?** После n шагов длина отрезка 1/2ⁿ. Условие 1/2ⁿ ≤ 10⁻⁶ даёт n ≥ log₂ 10⁶ ≈ 19,93, значит 20.

**Что значит квадратичная сходимость?** Ошибка следующего шага примерно пропорциональна квадрату предыдущей: 2,5·10⁻³ → 5·10⁻⁶ → 2·10⁻¹¹. Число верных знаков удваивается.

**Чем комбинированный метод лучше?** Даёт приближения с двух сторон одновременно: корень зажат, погрешность видна по разности x̄ₙ − xₙ; сходимость квадратичная.

**Как выбран k и что такое Q, q?** Q = max |f′| = 12,8 на отрезке, k > Q/2 = 6,4 гарантирует |φ′| < 1; взяли k = 7,4. Тогда q = max |φ′| = 0,73 < 1 — условие сходимости.

**Почему в итерациях первый шаг оказался справа от корня?** φ′(−2) = −0,73 < 0 — вблизи точки −2 отображение «переворачивает» порядок. Рядом с корнем φ′ ≈ +0,40 > 0, поэтому дальше сходимость монотонная («лестница»).

**Гарантирует ли условие |xₙ₊₁ − xₙ| < ε, что ошибка меньше ε?** Не всегда: для строгой гарантии нужны оценки (через m = 3,6, через q). В нашей задаче проверено: фактические ошибки всех методов меньше 10⁻⁶.

**Почему результаты отличаются в последних знаках?** Разные критерии остановки и разный момент остановки, но все в пределах ε от истинного корня −1,12491165.

**Что будет, если f′(x) = 0 в методе Ньютона?** Деление на ноль, метод ломается. У нас f′ ≥ 3,6 на отрезке, поэтому проблемы нет.

**Что делать, если на отрезке несколько корней?** Все эти методы найдут какой-то один или не сойдутся: поэтому сначала отделяют корни (разделы 2.1–2.6), чтобы на отрезке был ровно один.

**Как проверить ответ?** Подставить: f(−1,124912) по модулю порядка 10⁻⁶ (с точностью, которую мы заказывали); или сравнить все пять методов между собой.

## 13. Подводные камни и честные оговорки

- **«x₀ = −1 не подходит» в отчёте помощника.** Для Ньютона это сказано слишком категорично. Точнее: x₀ = −1 не удовлетворяет достаточному условию f·f″ > 0, хотя метод из этой точки тоже сошёлся бы (4 шага). На защите формулируй так: «выбрал левый конец, потому что для него выполнено f·f″ > 0, и это гарантирует монотонную сходимость».
- **Правило выбора неподвижного конца — про гарантию, а не про минимум шагов.** Если закрепить правый конец −1 и стартовать с −2, хорды тоже сойдутся (проверено: 7 шагов), но приближения будут прыгать по обе стороны от корня. Правило даёт монотонность и страхует от выхода за отрезок.
- **Критерий остановки.** Во всех методах, кроме дихотомии, это малость сдвига |xₙ₊₁ − xₙ|, а не проверка настоящей ошибки. Для нашего примера всё в порядке, но в общем случае так не всегда.
- **В коде нет защиты от бесконечного цикла.** Циклы `while (true)` остановятся только по условию точности. Для учебной задачи нормально; в серьёзном коде добавляют ограничение числа итераций и проверку деления на ноль.
- **Дихотомия не проверяет f(a)·f(b) < 0** внутри функции — условие проверено вручную в отчёте.
- **Q в итерациях находится сеткой с шагом 0,01.** Здесь f′ убывает, максимум в левом конце, поэтому находится точно 12,8. В общем случае это приближение, а не доказательство.
- **«Шаг» — это итерация цикла.** Шаг Ньютона (считает f и f′) и шаг хорд (только f) не равны по стоимости; сравнивать методы по числу шагов можно, но осознавая это.
