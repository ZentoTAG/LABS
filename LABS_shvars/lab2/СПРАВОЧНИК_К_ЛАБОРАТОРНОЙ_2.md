## 2. Как обосновать, что корень один и лежит на нужном отрезке

Функция — многочлен, поэтому непрерывна на всей числовой прямой. Её производные:

\[
f'(x)=3x^2-0{,}2x+0{,}4,\qquad f''(x)=6x-0{,}2.
\]

Дискриминант квадратичной функции \(f'\):

\[
D=(-0{,}2)^2-4\cdot3\cdot0{,}4=0{,}04-4{,}8=-4{,}76<0.
\]

Старший коэффициент \(f'\) положителен, а действительных корней у неё нет, значит \(f'(x)>0\) при любом \(x\). Следовательно, \(f\) строго возрастает и может иметь не более одного действительного корня.

На концах выбранного отрезка:

\[
f(-2)=-7{,}2<0,\qquad f(-1)=0{,}5>0.
\]

По теореме о промежуточных значениях корень на \([-2,-1]\) существует; из строгой монотонности он там единственный. Так одновременно выполнено отделение корня.

На этом отрезке \(f''(x)=6x-0{,}2<0\): вторая производная сохраняет знак. Кроме того,

\[
f'(-2)=12{,}8,\quad f'(-1)=3{,}6,\quad 3{,}6\le f'(x)\le12{,}8.
\]

Это важно для выбора начальных точек методов хорд и Ньютона и для метода итераций.

## 3. Что в программе отвечает за математику

### Функция и производные

```cpp
double f(double x)   { return x*x*x - 0.1*x*x + 0.4*x + 2; }
double df(double x)  { return 3*x*x - 0.2*x + 0.4; }
double ddf(double x) { return 6*x - 0.2; }
```

`f` вычисляет левую часть уравнения; `df` и `ddf` — её первую и вторую производные. Производная нужна для касательной Ньютона, а вторая производная — для стандартного выбора неподвижного конца хорды и начальной точки Ньютона.

### Точность и счётчик

```cpp
const double EPS = 1e-6;
```

`EPS` — малое положительное число \(10^{-6}\), используемое в критериях завершения циклов. Переменная `n` увеличивается на один за итерацию метода. Поэтому «шаг» в таблице — одна итерация алгоритма; это не обязательно одинаковое число вычислений функции у разных методов.

Методы получают `double& x` и `int& n`: ссылки позволяют записать найденное приближение и число шагов в переменные вызывающей функции. `main` передаёт каждому методу те же `a=-2`, `b=-1`, печатает результат, затем повторно использует переменные для следующего метода.

## 4. Метод половинного деления

### Идея и формулы

Если непрерывная функция на \([a,b]\) имеет значения разных знаков, корень внутри. Берём середину

\[
c_n=\frac{a_n+b_n}{2}
\]

и оставляем ту половину отрезка, на концах которой знаки разные. После каждого шага длина интервала уменьшается вдвое:

\[
b_n-a_n=\frac{b_0-a_0}{2^n}.
\]

Приближением служит середина последнего интервала. Если остановиться при длине \(\le\varepsilon\), ошибка середины относительно корня не больше половины этой длины.

### Что делает код

```cpp
while (fabs(b - a) > EPS) {
    x = (a + b) / 2.0;
    if (f(a) * f(x) <= 0) b = x;
    else a = x;
    n++;
}
x = (a + b) / 2.0;
```

Проверка произведения неравенством нулю выбирает половину с переменой знака; равенство нулю тоже корректно оставляет найденный точный корень на границе новой половины. После цикла середина вычисляется ещё раз уже для окончательного интервала.

### Свойства и результат

- Для сходимости нужны непрерывность и смена знака на концах; здесь оба условия выполнены.
- Приближение контролируется вложенными интервалами, поэтому метод надёжен.
- Сходимость линейная: интервал каждый раз становится вдвое короче.
- Программа: `-1.1249118`, **20 шагов**.

## 5. Метод хорд с неподвижным концом

### Геометрический смысл и формула

Через точки графика \((x_{\rm curr},f(x_{\rm curr}))\) и \((x_{\rm fixed},f(x_{\rm fixed}))\) проводится секущая — хорда. Её пересечение с осью \(Ox\) имеет абсциссу

\[
x_{n+1}=x_n-\frac{f(x_n)}{f(x_n)-f(x_{\rm fixed})}(x_n-x_{\rm fixed}).
\]

Один конец закреплён, второй перемещается. Для выбранной схемы неподвижным выбирают конец, где \(f(x)f''(x)>0\), а стартуют с другого конца. Здесь

\[
f(-2)f''(-2)=(-7{,}2)(-12{,}2)>0,
\]

поэтому закреплён \(a=-2\), подвижное начальное приближение \(x_0=b=-1\).

### Что делает код

```cpp
if (f(a) * ddf(a) > 0) {
    fixed_end = a;
    x_curr = b;
} else {
    fixed_end = b;
    x_curr = a;
}
...
double x_next = x_curr - f(x_curr) / (f(x_curr) - f(fixed_end))
                * (x_curr - fixed_end);
```

Сначала выбирается неподвижная точка по произведению \(f(a)f''(a)\), затем применяется формула пересечения хорды с осью. Цикл заканчивается, когда соседние подвижные приближения различаются менее чем на `EPS`.

### Свойства и результат

- Для стандартного обоснования сходимости на отрезке требуют, чтобы \(f'\) и \(f''\) сохраняли знак, а неподвижный конец был выбран по указанному правилу. Здесь условия выполнены.
- Приближения идут с одной стороны; для этой задачи последовательность стартует справа от корня и убывает.
- Сходимость обычно линейная.
- Программа: `-1.1249111`, **16 шагов**.

## 6. Метод Ньютона (касательных)

### Геометрический смысл и формула

В точке \((x_n,f(x_n))\) строится касательная. Её наклон равен \(f'(x_n)\); пересечение касательной с осью \(Ox\) становится новым приближением:

\[
x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}.
\]

Начальную точку выбирают так, чтобы \(f(x_0)f''(x_0)>0\). Здесь это левый конец:

\[
f(-2)f''(-2)>0,\qquad f(-1)f''(-1)<0,
\]

поэтому \(x_0=-2\).

### Что делает код

```cpp
double x_curr = (f(a) * ddf(a) > 0) ? a : b;
double x_next = x_curr - f(x_curr) / df(x_curr);
```

Тернарный оператор выбирает стартовую точку. На каждом шаге вычисляется касательное приближение. Здесь производная положительна и не обращается в ноль, так что деление корректно.

### Свойства и результат

- При гладкой функции, подходящем начальном приближении и ненулевой производной метод сходится локально; здесь геометрические условия выполнены.
- Приближения в этой задаче подходят к корню с левой стороны.
- Вблизи простого корня сходимость квадратичная: грубо говоря, ошибка следующего шага пропорциональна квадрату текущей ошибки.
- Программа: `-1.1249117`, **6 шагов**.

## 7. Комбинированный метод хорд и касательных

### Идея

Одновременно строятся касательное и хордовое приближения, удерживающие корень между собой. Для данного отрезка касательная начинается в \(x_n=-2\), а хорда — с противоположной стороны \(\bar x_n=-1\):

\[
x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)},
\]

\[
\bar x_{n+1}=\bar x_n-\frac{f(\bar x_n)}{f(\bar x_n)-f(x_n)}(\bar x_n-x_n).
\]

Первое приближение подходит с левой стороны, второе — с правой. Когда расстояние между ними мало, корень зажат в коротком интервале.

### Что делает код

```cpp
double x_n_next = x_n - f(x_n) / df(x_n);
double x_bar_next = x_bar - f(x_bar) / (f(x_bar) - f(x_n))
                    * (x_bar - x_n);
...
if (fabs(x_n_next - x_bar_next) < EPS) {
    x = (x_n_next + x_bar_next) / 2.0;
```

На каждой итерации сначала вычисляется следующий шаг Ньютона, затем следующий шаг хорды. Если новые приближения достаточно близки, возвращается их среднее арифметическое.

### Свойства и результат

- При выполнении условий выбора сторон сохраняется зажимание корня с двух сторон.
- Это даёт наглядный контроль интервала; расстояние между сторонами — естественная оценка локализации корня.
- Для гладкой функции комбинированный метод вблизи корня имеет высокую, обычно квадратичную, скорость сходимости.
- Программа: `-1.1249117`, **5 шагов**.

## 8. Метод простых итераций

### Приведение к неподвижной точке

Уравнение \(f(x)=0\) переписывается как \(x=\varphi(x)\). В коде выбрано

\[
\varphi(x)=x-\frac{f(x)}{k},\qquad x_{n+1}=\varphi(x_n).
\]

Неподвижная точка этой функции является корнем: если \(x=\varphi(x)\), то \(x=x-f(x)/k\), откуда при \(k\ne0\) следует \(f(x)=0\).

Производная итерационной функции:

\[
\varphi'(x)=1-\frac{f'(x)}{k}.
\]

Достаточное условие сходимости на интервале: \(|\varphi'(x)|\le q<1\) и отображение сохраняет интервал (либо рассматриваемую область). Здесь по концам \(f'\) принимает значения от 3,6 до 12,8. При идеальном максимуме \(Q=12{,}8\) код выбрал бы \(k=Q/2+1=7{,}4\), и на исходном отрезке

\[
\max |\varphi'(x)|=\max\left(|1-3{,}6/7{,}4|,|1-12{,}8/7{,}4|\right)
\approx0{,}730<1.
\]

Значит, производная итерационной функции по модулю меньше единицы. На практике программа находит \(Q\) перебором точек через `0.01`, а не аналитически.

### Что делает код

```cpp
double Q = 0;
for (double t = a; t <= b; t += 0.01)
    if (fabs(df(t)) > Q) Q = fabs(df(t));
double k = Q / 2.0 + 1.0;
double x_curr = a;
double x_next = x_curr - f(x_curr) / k;
```

Цикл оценивает максимум модуля первой производной на сетке; затем задаётся положительное `k`, а начальным значением служит `a`. Знак `k` согласован со знаком `f'`, который здесь всюду положителен.

### Важное уточнение про оценку Q

Теоретически для этой функции максимум на отрезке равен \(12{,}8\), поскольку \(f'\) убывает на \([-2,-1]\) (там \(f''<0\)). Но сетка с вещественным шагом `0.01` не является строгим доказательством глобального максимума и из-за накопления ошибки шага может слегка не попасть в конец отрезка. Для строгой защиты лучше сказать: «аналитически \(Q=12{,}8\); программа оценивает его сеточным перебором и получает значение, близкое к этому». Выбор `k = Q / 2 + 1` оставляет запас относительно границы \(Q/2\).

### Свойства и результат

- Скорость линейная; около корня коэффициент сжатия связан с \(|\varphi'(\xi)|\).
- Начальный шаг может перескочить на другую сторону: из \(x_0=-2\) получается приближение справа от корня. Дальше значения монотонно приближаются к корню.
- Программа: `-1.1249113`, **15 шагов**.

## 10. Точность и тонкие места реализации

Это особенно полезно проговорить, если преподаватель спросит, что именно гарантирует `EPS`.

### Критерии остановки в коде

- **Дихотомия:** `fabs(b-a) <= EPS`. Здесь интервал корня действительно сужен до заданной длины, а возвращается его середина; ошибка результата не больше `EPS/2`.
- **Хорды и Ньютон:** проверяется `fabs(x_next-x_curr) < EPS`.
- **Итерации:** проверяется `fabs(x_next-x_curr) < EPS`.
- **Комбинированный метод:** проверяется расстояние между следующими хордовым и касательным приближениями.

Последнее изменение меньше `EPS` само по себе **не всегда** доказывает, что абсолютная ошибка относительно корня меньше `EPS`. Для строгой оценки нужны дополнительные условия и оценка остатка/сжатия. Например, если на отрезке \(|f'(x)|\ge m>0\), то по теореме Лагранжа

\[
|x-\xi|\le \frac{|f(x)|}{m}.
\]

Для данной задачи на исходном отрезке можно взять \(m=3{,}6\), поэтому невязка \(|f(x)|\) даёт строгую оценку ошибки \(|f(x)|/3{,}6\), когда приближение остаётся на этом отрезке. Для метода итераций действует апостериорная оценка с коэффициентом сжатия \(q\):

\[
|\xi-x_n|\le\frac{q}{1-q}|x_n-x_{n-1}|.
\]

В самой программе эти оценки не вычисляются: она использует только критерии разности приближений (кроме интервала в дихотомии).

### Что можно улучшить, если спросят про надёжность

1. Добавить ограничение максимального числа итераций, чтобы цикл не работал бесконечно при неверных входных данных или потере сходимости.
2. Проверять исходное условие `f(a) * f(b) < 0` в методе половинного деления.
3. В методах хорд и Ньютона проверять малость невязки или вычислять апостериорную оценку ошибки, а не полагаться только на разность соседних приближений.
4. Максимум \(|f'|\) для этой конкретной задачи вычислить аналитически по монотонности производной, а не сеткой. Для универсальной функции можно применять гарантированный способ оценки.
5. После получения ответа проверять `isfinite`, ненулевой знаменатель и близость результата к исходному отрезку.

## 11. Основные понятия для устного ответа

- **Корень уравнения** — число \(\xi\), для которого \(f(\xi)=0\).
- **Отделение корня** — установление отрезка, содержащего ровно один корень.
- **Невязка** — величина \(|f(x_n)|\); она показывает, насколько приближение удовлетворяет исходному уравнению, но не всегда совпадает с ошибкой \(|x_n-\xi|\).
- **Ошибка** — \(|x_n-\xi|\), где \(\xi\) — точный корень.
- **Линейная сходимость** — ошибка на каждом шаге примерно умножается на постоянный коэффициент меньше единицы.
- **Квадратичная сходимость** — вблизи корня ошибка следующего шага пропорциональна квадрату предыдущей, поэтому точность быстро растёт.
- **Монотонное приближение** — последовательность приближений движется к корню с одной стороны; **зажимание** — две оценки удерживают корень между собой.
- **Неподвижная точка** — число \(\xi\), для которого \(\varphi(\xi)=\xi\); при выбранном преобразовании это эквивалентно \(f(\xi)=0\).
- **`Q` и `q` в методе итераций**: \(Q=\max|f'|\) — характеристика исходной функции; \(q=\max|\varphi'|\) — коэффициент сжатия итерационного отображения. Это разные величины.

## 12. Типичные вопросы преподавателя и короткие ответы

**Почему корень единственный?**  
Потому что \(f'(x)>0\) на всей прямой, следовательно, функция строго возрастает. На концах \([-2,-1]\) значения разных знаков, значит там есть корень; из монотонности он единственный.

**Зачем нужна вторая производная?**  
Она показывает выпуклость/вогнутость и участвует в стандартном выборе начальной точки метода Ньютона и неподвижного конца метода хорд через условие \(f(x)f''(x)>0\).

**Почему в Ньютона старт с \(-2\), а не с \(-1\)?**  
Потому что на левом конце \(f(-2)f''(-2)>0\), а на правом это произведение отрицательно. Выбор согласован с достаточным условием для классической схемы.

**Почему половинное деление медленнее, но надёжнее?**  
Оно гарантированно сохраняет смену знака и уменьшает интервал вдвое на каждом шаге; скорость предсказуема, но лишь линейная. Быстрые методы используют производные/геометрию и сильнее зависят от условий.

**Почему метод Ньютона так быстро сошёлся?**  
Корень простой, производная рядом с ним не равна нулю, а стартовая точка выбрана удачно. Вблизи такого корня метод имеет квадратичную сходимость.

**Как получается формула Ньютона?**  
Линеаризуем функцию около текущего приближения: \(f(x)\approx f(x_n)+f'(x_n)(x-x_n)\). Приравниваем линейное приближение нулю и решаем относительно \(x\): получаем \(x_{n+1}=x_n-f(x_n)/f'(x_n)\).

**Как выбирается `k` в итерациях?**  
Так, чтобы отображение \(\varphi(x)=x-f(x)/k\) было сжимающим. Здесь `k` положителен, как \(f'\), и больше половины максимума \(|f'|\); программа использует `Q/2 + 1`.

**Что означает 20 шагов дихотомии?**  
Начальная длина равна 1, а после 20 шагов — \(1/2^{20}\approx9{,}54\cdot10^{-7}\), что меньше `EPS`.

**Почему ответы методов отличаются на последних знаках?**  
Разные критерии остановки и порядок округления дают слегка разные приближения. В пределах требуемой точности они соответствуют одному корню.

**Гарантирует ли `fabs(x_next-x_curr) < EPS` ошибку корня меньше `EPS`?**  
Не автоматически. Это практический критерий стабилизации последовательности. Для строгой гарантии нужны условия метода и апостериорная оценка. В дихотомии гарантия напрямую следует из длины сохраняемого интервала.

**Почему код считает `Q` шагом `0.01`?**  
Это численное приближение максимума производной на отрезке. Для нашей функции максимум можно точно обосновать аналитически: \(f''<0\), значит \(f'\) убывает и \(Q=f'(-2)=12{,}8\). Сетка удобна в программе, но в общем случае не является строгой гарантией максимума.

## 13. Что показать на рисунке при объяснении методов

- **Половинное деление:** отметить концы отрезка с противоположными знаками, середину и ту половину, которая сохраняется.
- **Хорды:** провести секущую от фиксированной точки графика к текущей подвижной; пересечение с осью `Ox` — следующее приближение.
- **Ньютон:** в текущей точке графика провести касательную; её пересечение с `Ox` даёт следующее приближение.
- **Комбинированный:** показать касательную с левой стороны и хорду с правой; две новые абсциссы зажимают корень.
- **Итерации:** изобразить графики \(y=\varphi(x)\) и \(y=x\); их пересечение — неподвижная точка. Шаги последовательности строятся «лестницей» между этими графиками.
